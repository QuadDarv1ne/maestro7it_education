# Шпаргалка: Системные URI-команды Windows

Эти команды можно использовать для быстрого запуска системных приложений и настроек Windows. Они отлично работают в диалоговом окне «Выполнить» (`Win + R`), в адресной строке Проводника, а также в сторонних программах вроде **X-Mouse Button Control** (через действие **"Run Application"**).

## 📸 Скриншоты и запись
| Действие | Команда |
|---|---|
| Открыть панель создания скриншота (`Win+Shift+S`) | `ms-screenclip:` |
| Открыть «Ножницы» (Windows 11) | `ms-ScreenSketch:` |

## 💡 Как использовать

1. **В X-Mouse Button Control:** 
   В настройках нужной кнопки выберите действие **"Run Application"** и введите команду (например, `ms-screenclip:`).
2. **В диалоговом окне «Выполнить»:** 
   Нажмите `Win + R`, введите команду и нажмите `Enter`.
3. **В Проводнике:** 
   Введите команду в адресную строку и нажмите `Enter`.

> ⚠️ **Примечание:** Не все URI-команды работают одинаково хорошо на разных версиях Windows. Некоторые команды, особенно связанные с настройками, могут отличаться в Windows 10 и Windows 11. Если какая-то команда не срабатывает, попробуйте найти её актуальный аналог для вашей версии системы.
