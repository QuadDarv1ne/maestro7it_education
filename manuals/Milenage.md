# Milenage: архитектура и программирование

## 1. Что это

**Milenage** — эталонный набор криптографических функций, разработанный **ETSI SAGE** по запросу **3GPP**. Он используется для аутентификации и генерации ключей (AKA) в сетях **3G, 4G и 5G**.

Milenage описывает, как SIM/USIM и сеть доказывают подлинность и согласуют ключи шифрования.

---

## 2. Криптографическая архитектура

### 2.1. Ядро

Milenage построен на блочном шифре **AES-128**. Все функции используют ядро E_K, где K — 128-битный секретный ключ абонента.

### 2.2. Константы

Стандарт 3GPP TS 35.206 определяет константы c1–c5 и ротационные константы r1–r5.

### 2.3. Формулы

Базовое вычисление:

    TEMP = E_K(RAND XOR OP_C)

Далее:

    f1: MAC-A = E_K(TEMP XOR rot(IN1, r1) XOR c1) XOR OP_C
    f2: RES   = E_K(rot(TEMP XOR OP_C, r2) XOR c2) XOR OP_C
    f3: CK    = E_K(rot(TEMP XOR OP_C, r3) XOR c3) XOR OP_C
    f4: IK    = E_K(rot(TEMP XOR OP_C, r4) XOR c4) XOR OP_C
    f5: AK    = E_K(rot(TEMP XOR OP_C, r5) XOR c5) XOR OP_C

где:

    IN1 = SQN || AMF || SQN || AMF

### 2.4. Функции

| Функция | Назначение | Выход |
|---|---|---|
| f1 | MAC для аутентификации сети | MAC-A |
| f1* | MAC для ресинхронизации | MAC-S |
| f2 | Ответ | RES / XRES |
| f3 | Ключ шифрования | CK |
| f4 | Ключ целостности | IK |
| f5 | Ключ анонимности | AK |
| f5* | Ключ анонимности для ресинхронизации | AK* |

### 3.1. Реализации

| Язык | Ресурс |

| Java | com.github.brake.threegpp:milenage |

### 3.2. Пример на C

В FreeRADIUS реализация Milenage вычисляет TEMP, затем функции f1–f5. Каждая функция принимает:

- opc — OP_C;
- k — секретный ключ;
- rand;
- sqn;
- amf.

### 3.3. Требования к eUICC

GSMA SGP.22 требует, чтобы eUICC поддерживал Milenage и TUAK. Реализация должна быть устойчива к атакам по сторонним каналам.

### 3.4. Тестовые векторы

Тестовые данные определены в:

- 3GPP TS 35.207;
- 3GPP TS 35.208.

## 4. Безопасность и чувствительность к взлому

Milenage не является практически взломанным. Однако у него есть теоретические слабости.

### 4.1. Теоретические weaknesses

Независимый анализ выявил:

- одну значительную слабость;
- одну незначительную слабость.

Одна из теоретических атак требует сложности порядка 2^65 операций. На практике это неосуществимо.

### 4.2. Практическая стойкость

Известных практических атак на процедуру AKA через Milenage нет.

### 4.3. Чувствительность реализации

Milenage чувствителен к:

- side-channel attacks;
- fault injection;
- утечке ключа K;
- утечке OP_C;
- слабой защите AES-ядра.

### 4.4. Зависимость от AES

Если в AES найдут практические уязвимости, Milenage также окажется под угрозой.

**Вывод:** Milenage криптографически устойчив для практического применения, но требует защищённой реализации и хранения ключей.
