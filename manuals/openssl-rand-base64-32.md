# Мануал: `openssl rand -base64 32`

## Назначение

Команда `openssl rand -base64 32` генерирует **32 случайных байта** (256 бит) с помощью криптографически стойкого генератора псевдослучайных чисел (CSPRNG) из библиотеки OpenSSL и выводит результат в кодировке **Base64**.

**Такая строка часто используется как:**

- секретный ключ;
- API-токен;
- пароль для сервиса;
- соль (salt) или IV;
- случайный идентификатор;
- значение для `SECRET_KEY`, `JWT_SECRET`, `APP_KEY` и т.п.

> Важно: `32` — это **количество байт**, а не длина итоговой строки.  


> 32 байта = 256 бит. В Base64 это **44 символа** плюс перевод строки.

---

## Синтаксис

```bash
openssl rand [опции] число_байт
```

Для рассматриваемой команды:

```bash
openssl rand -base64 32
```

**Где:**

- `openssl` — утилита OpenSSL;
- `rand` — подкоманда генерации случайных данных;
- `-base64` — кодировать вывод в Base64;
- `32` — количество случайных байт.

---

## Что получается на выходе

**Пример:**

```bash
$ openssl rand -base64 32
qX7v3kP9sL2mN8fR4tY6uZ1aW5cB0dE7gH3jK9lM2nP=
```

**Характеристики:**

- случайных байт: 32;
- бит: 256;
- символов Base64: 44 (включая `=`);
- перевод строки: 1;
- всего байт в выводе: 45.

**Проверка длины:**

```bash
openssl rand -base64 32 | wc -c
# 45
```

Если убрать перевод строки:

```bash
openssl rand -base64 32 | tr -d '\n' | wc -c
# 44
```

**Если нужна строка ровно из 32 символов `Base64`, то нужно 24 байта:**

```bash
openssl rand -base64 24
# 32 символа Base64
```

---

## Опции `openssl rand`

| Опция | Описание |
|-------|----------|
| `-base64` | Кодировать вывод в Base64 |
| `-hex` | Кодировать вывод в hex |
| `-out file` | Записать результат в файл |
| `-rand file...` | Использовать дополнительные источники энтропии |
| `-engine id` | Использовать указанный криптографический engine |
| `-help` | Показать справку |

## Примеры использования

### 1. Базовый пример

```bash
openssl rand -base64 32
```

### 2. Записать секрет в переменную

```bash
SECRET=$(openssl rand -base64 32)
echo "$SECRET"
```

Командная подстановка `$(...)` удалит завершающий перевод строки, поэтому в переменной будет 44 символа `Base64`

### 3. Сохранить в файл

```bash
openssl rand -base64 32 > secret.txt
chmod 600 secret.txt
```

### 4. Сохранить в бинарном виде

```bash
openssl rand -out secret.bin 32
```

### 5. Hex-представление

```bash
openssl rand -hex 32
# 64 hex-символа
```

### 6. URL-безопасный вариант

```bash
openssl rand -base64 32 | tr '+/' '-_' | tr -d '='
```

### 7. Проверить энтропию и длину

```bash
openssl rand -base64 32 | wc -c
openssl rand -base64 32 | base64 -d | wc -c
# 32
```

### 8. Использование в Docker / CI

```bash
export APP_KEY="$(openssl rand -base64 32)"
```

## Безопасность

- `openssl rand` использует CSPRNG, пригодный для криптографических задач.
- Base64 — это **кодирование**, а не шифрование. Строку можно легко декодировать.
- Не логируйте секреты в открытом виде.
- Не коммитьте секреты в Git.
- Ограничивайте права доступа к файлам: `chmod 600`.
- Не используйте `-rand` без необходимости: это может снизить безопасность, если подсунуть предсказуемый файл.
- 256 бит энтропии — достаточно для большинства практических задач.
- Для паролей, которые человек должен вводить вручную, Base64 неудобен: там есть `+`, `/`, `=`. Лучше использовать `pwgen`, `pass` или `openssl rand -hex`.

---

## Частые ошибки

| Ошибка | Причина / решение |
|--------|-------------------|
| `openssl: command not found` | OpenSSL не установлен. Установите: `apt install openssl`, `yum install openssl`, `brew install openssl` |
| `rand: Use -help for summary` | Неверные опции. Проверьте синтаксис |
| `Invalid number` | Число байт должно быть положительным целым |
| Секрет слишком короткий | Помните: `-base64 32` — это 32 байта, а не 32 символа |
| В строке есть перевод строки | Используйте `tr -d '\n'` или `$(...)` |

## Альтернативы

```bash
# Linux / macOS
head -c 32 /dev/urandom | base64
dd if=/dev/urandom bs=32 count=1 2>/dev/null | base64

# Python
python3 -c "import os,base64; print(base64.b64encode(os.urandom(32)).decode())"

# OpenSSL hex
openssl rand -hex 32

# UUID (не 256 бит, но часто достаточно)
uuidgen
```
